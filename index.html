How to wire in real live data

Want the explainer to double-check itself? Use this mini playbook to turn the text clues into coordinates, compare the sky against real telemetry, then feed the context into the scoring logic above.

  1. Geocode the sighting

    Convert the free-form location text into latitude / longitude so every downstream API knows where to look. 

    async function geocode(location) {
  const url = `https://nominatim.openstreetmap.org/search?format=json&q=${encodeURIComponent(location)}`;
  const [hit] = await fetch(url, { headers: { 'User-Agent': 'NotAliens demo' } }).then((r) => r.json());
  return hit ? { lat: Number(hit.lat), lon: Number(hit.lon) } : null;
}

  2. Check satellites & launches

    Pull the current Starlink TLE set (or Launch Library 2 schedule) and compute passes around the timestamp using an SGP4 helper such as satellite.js. 

    import { propagate, gstime } from 'satellite.js';
const tle = await fetch('https://celestrak.org/NORAD/elements/gp.php?GROUP=starlink&FORMAT=json').then((r) => r.json());
// Run propagate() for each TLE, compare the resulting az/el with your geocoded lat/lon and reportForm time.

  3. Cross-check aircraft

    Services such as AirLabs, AeroAPI, or ADS-B Exchange provide bounding-box queries so you can spot planes / helicopters that match the duration. 

    const flights = await fetch(`https://airlabs.co/api/v9/flights?api_key=YOUR_KEY&bbox=${bboxFrom(lat, lon)}`).then((r) => r.json());
const hovering = flights.response.filter((plane) => plane.dir < 15 || plane.speed < 60);

  4. Layer in weather + aurora

    Visibility, cloud height, Kp index, or auroral oval probability all help explain glowing clouds. 

    const meteo = await fetch(`https://api.open-meteo.com/v1/forecast?latitude=${lat}&longitude=${lon}&hourly=cloudcover,visibility&current_weather=true`).then((r) => r.json());
const aurora = await fetch('https://services.swpc.noaa.gov/json/ovation_aurora_latest.json').then((r) => r.json());
