How to wire in real live data

Want the explainer to double-check itself? Use this playbook to turn text clues into coordinates, compare the sky against real telemetry, then feed the context into the scoring logic above.

  1. Geocode the sighting

    Convert the free-form location text into latitude / longitude so every downstream API knows where to look. 

    async function geocode(location) {
  const url = `https://nominatim.openstreetmap.org/search?format=json&q=${encodeURIComponent(location)}`;
  const [hit] = await fetch(url, { headers: { 'User-Agent': 'NotAliens demo' } }).then((r) => r.json());
  return hit ? { lat: Number(hit.lat), lon: Number(hit.lon) } : null;
}
